# cod_fyt2024_vision 算法优化实现状态

本文记录 `cod_fyt2024_vision` 对算法优化总结的最终实现状态。对照完成后，参考项目 `sentry-auto-aim` 已删除；所有有价值的算法结论和实现均已固化在本项目中。

## 已实现

- 装甲板姿态使用全局粗到细 yaw 重投影搜索，替代 G2O/Sophus BA。
- PnP 多解筛选默认开启，并使用同一候选解的旋转和平移向量。
- 数字 ROI 使用 `20 x 25`，再缩放到 `28 x 28`。
- 检测参数运行配置为 `min_light_ratio: 0.6`、`max_large_center_distance: 9.0`。
- EKF 修正 Q 矩阵变量，使用 Joseph 协方差更新，并启用 50 帧 NIS 发散检测。
- 装甲板跳变阈值为 `0.2 rad`，半径限制为 `0.12–0.27 m`，四装甲板换板时清除 z 速度。
- 飞行时间最多迭代 10 次，并按预测后的最近装甲板更新距离。
- 低速最近板锁定、高速 coming/leaving 非对称选板和无候选回退策略已实现。
- 动态火控同时检查 yaw 和 pitch；中心跟踪明确禁止开火。
- `yaw_offset`、`pitch_offset` 已作为运行参数加入。
- 高 yaw 速度 pitch 下压补偿已参数化，默认阈值 `6 rad/s`、参考速度 `10 rad/s`、上限 `1.2°`。

## 当前参数策略

- `min_switching_v_yaw: 1.0`
- `coming_angle: 55.0°`
- `leaving_angle: 20.0°`

旧版 `side_angle` 已由 coming/leaving 非对称窗口替代，不再参与选板。

## 文档修订说明

- PnP 多解切换不再对所有平移向量求平均，而是使用所选候选解的完整位姿。
- `isOnTarget()` 已经是二维 yaw/pitch 判定，不再是仅比较 yaw。
- 中心跟踪会计算最终修正后的瞄准角，但因中心点不对应可射击装甲板而禁止开火。

## 验证状态

- 检测和解算配置已通过 YAML 解析检查。
- EKF、BaSolver 和瞄准修正逻辑已完成独立语法/编译检查。
- 瞄准修正回归测试覆盖偏置、yaw 归一化、正负角速度、阈值、单调性和上限，测试全部通过。
- 完整 ROS 2 `colcon build` 仍受当前环境缺少 `ament_cmake` 及相关依赖限制。
